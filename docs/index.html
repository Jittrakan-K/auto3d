              Create .SLDPRT with SOLIDWORKS on this PC

              1. Once: download the desktop app (.zip), extract it and run install.bat (or update.bat if installed)
              2. Click Create again. When the browser asks to open the app, tick "Always allow" and open it
              3. Allow local network access if the browser asks

              Still stuck? Keep start.bat running instead. Stop the background app with stop.bat

              Open in SOLIDWORKS

              With feature tree, nothing to install

              Set up the button Once

              1. Copy the launcher code
              2. Tools › Macro › New, save as AUTO_DESIGN_3D.swp
              3. Paste over all the code, then press Ctrl+S
              4. Tools › Customize › Commands › Macro, drag New Macro Button to a toolbar and pick the .swp

              For each part

              1. Download the SOLIDWORKS macro from the file cards
              2. Click your button. The .SLDPRT is saved to Downloads

              Saved in the SOLIDWORKS version that runs it. No button? Use Tools › Macro › Run
