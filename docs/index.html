        ลำดับการสร้าง

          สร้าง .SLDPRT ด้วย SOLIDWORKS ในเครื่อง

          1. ครั้งแรกครั้งเดียว: ในโฟลเดอร์โปรเจกต์ AUTO DESIGN 3D บนเครื่อง ดับเบิลคลิก setup_web_link.bat (ถ้ายังไม่เคยติดตั้ง ให้รัน install.bat ก่อน)
          2. กดปุ่ม สร้างไฟล์ อีกครั้ง เบราว์เซอร์จะถามว่าเปิด AUTO DESIGN 3D ไหม ติ๊ก "อนุญาตเสมอ" แล้วกดเปิด ครั้งต่อไปจะเปิดเองโดยไม่ถาม
          3. ถ้าเบราว์เซอร์ถามว่าให้เว็บเข้าถึงอุปกรณ์ในเครื่องหรือเครือข่าย ให้กดอนุญาต

          ยังใช้ไม่ได้ ดับเบิลคลิก start.bat เปิดทิ้งไว้แทนได้ แอปที่เว็บเปิดให้จะทำงานเงียบ ๆ ไม่มีหน้าต่าง ปิดด้วย stop.bat หรือรีสตาร์ทเครื่อง

          ไฟล์ SOLIDWORKS พร้อม Feature Tree

          1. กดดาวน์โหลดแถว SOLIDWORKS ได้ไฟล์ zip แล้วแตกไฟล์ก่อน
          2. เปิด SOLIDWORKS ไปที่ Tools › Macro › Run แล้วเลือกไฟล์ .swb
          3. ได้ไฟล์ .SLDPRT พร้อม Feature Tree ในโฟลเดอร์เดียวกัน แก้ขนาดต่อได้ทุกฟีเจอร์

          ไฟล์ .SLDPRT เป็นรุ่นเดียวกับ SOLIDWORKS ที่รันมาโคร รุ่นเก่าเปิดไฟล์จากรุ่นใหม่ไม่ได้ ถ้าต้องส่งให้คนที่ใช้ 2018 ให้รันมาโครใน 2018 มาโครตรวจปริมาตรทุกฟีเจอร์ ถ้าไม่ตรงจะแจ้งชื่อฟีเจอร์
