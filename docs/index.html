            ลำดับการสร้าง

              สร้าง .SLDPRT ด้วย SOLIDWORKS ในเครื่อง

              1. ครั้งแรกครั้งเดียว: ดาวน์โหลดแอปบนเครื่อง (.zip) แตกไฟล์ แล้วดับเบิลคลิก install.bat ถ้าเคยติดตั้งแล้ว ดับเบิลคลิก update.bat แทน
              2. กดปุ่ม สร้างไฟล์ อีกครั้ง เบราว์เซอร์จะถามว่าเปิด AUTO DESIGN 3D ไหม ติ๊ก "อนุญาตเสมอ" แล้วกดเปิด ครั้งต่อไปจะเปิดเองโดยไม่ถาม
              3. ถ้าเบราว์เซอร์ถามว่าให้เว็บเข้าถึงอุปกรณ์ในเครื่องหรือเครือข่าย ให้กดอนุญาต

              ยังใช้ไม่ได้ ดับเบิลคลิก start.bat เปิดทิ้งไว้แทนได้ แอปที่เว็บเปิดให้จะทำงานเงียบ ๆ ไม่มีหน้าต่าง ปิดด้วย stop.bat หรือรีสตาร์ทเครื่อง

              แก้แผนงาน JSON

              เปิดใน SOLIDWORKS พร้อม Feature Tree

              ใช้ได้กับคอมบริษัท ไม่ต้องติดตั้งโปรแกรมเพิ่ม

              ตั้งปุ่มลัด ครั้งเดียว

              2. Tools › Macro › New ตั้งชื่อ AUTO_DESIGN_3D.swp
              3. วางโค้ดทับทั้งหมด (Ctrl+A, Ctrl+V) แล้ว Ctrl+S
              4. Tools › Customize › Commands › Macro ลาก New Macro Button ไปที่แถบเครื่องมือ เลือกไฟล์ .swp

              ใช้งาน ทุกครั้ง

              1. ดาวน์โหลด มาโคร .swb จากการ์ดใต้ชิ้นงาน
              2. กดปุ่มลัดใน SOLIDWORKS ได้ .SLDPRT ในโฟลเดอร์ Downloads

              ไฟล์ .SLDPRT เป็นรุ่นเดียวกับ SOLIDWORKS ที่ใช้รัน ไม่ตั้งปุ่มก็ได้ ใช้ Tools › Macro › Run แทน

              ตั้งค่า

              ไม่จำเป็นถ้าใช้ Claude Pro ผ่านแชต คีย์ API คิดเงินแยกจาก Claude Pro คีย์ส่งตรงจากเบราว์เซอร์ไปที่ Claude เท่านั้น ไม่ผ่านเซิร์ฟเวอร์อื่น ถ้าไม่ติ๊กจำไว้ คีย์จะหายเมื่อปิดแท็บ ค่าใช้จ่ายคิดกับบัญชีของคีย์นี้

              claude-opus-5-5 อ่าน Drawing ได้ละเอียดกว่า claude-sonnet-5-5 ถูกและเร็วกว่า
